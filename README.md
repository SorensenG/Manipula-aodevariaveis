# Manipulação de Variáveis CSS com JavaScript

Este projeto permite manipular variáveis CSS (como borda, desfoque, tamanho e cor) em tempo real usando controles deslizantes e um seletor de cor. A interação entre o HTML, CSS e JavaScript permite uma experiência dinâmica, atualizando as propriedades da página à medida que o usuário ajusta os controles.

## Funcionalidades

- Ajuste da borda da imagem
- Controle do desfoque (blur) da imagem
- Alteração do tamanho da imagem
- Seleção de cor de fundo e borda

## Tecnologias

- HTML
- CSS (incluindo variáveis CSS)
- JavaScript
